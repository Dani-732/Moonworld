# 圣杯战争 MVP 冒烟测试

## 准备

1. 完全退出并重启 RimWorld 1.6，按顺序启用 `Harmony`、`Humanoid Alien Races`、`Holy Grail War - Servant Test` 和 `MoonWorld`。本次依赖/Def/组件变更需要重启游戏，仅重读存档不够。
2. 首先关闭开发者模式，选择中文剧本“月世界：降灵之兆”。下面的正式开局矩阵优先于历史调试准备步骤。
3. 失败注入、两名回路持有者准备等辅助检查可使用独立测试副本；不得将开发者触发事件当作自然事件频率已经验收。

## 检查步骤

### 七职阶依赖与召唤池（本轮优先验收入口）

准备：完全退出并重启游戏，前置 Holy Grail War 使用包含七名英灵的版本，保存旧档副本。此节只扩充候选，战争仍为玩家加一个敌方阵营。

| 职阶 | 候选 | 沿用前置的初始外观/装备重点 |
|---|---|---|
| Saber | 阿尔托莉雅·潘德拉贡 | 礼装、金发、誓约胜利之剑 |
| Archer | 卫宫士郎 | 红色外套、白发、弓及背包干将莫邪 |
| Lancer | 库·丘林 | 蓝色战衣、发型、Gae Bolg |
| Assassin | 佐佐木小次郎 | 和服、发型 |
| Caster | 美狄亚 | 长袍、发型 |
| Rider | 美杜莎 | 礼装、眼罩、发型 |
| Berserker | 赫拉克勒斯 | 全身专用贴图、顶部头像、无原版身体叠出 |

前置当前没有为 Assassin、Caster、Rider、Berserker 的身份配置强制初始武器；本轮不在 MoonWorld 中补造。外观应与前置 Mod 自身生成的同名角色一致。

1. 从未使用召唤资格的新局/存档开始，关闭开发者模式，接受战争事件、指定御主，再使用正式召唤按钮选有效落点。应出现表内一名英灵，且仅消耗指定御主本届的一次资格。
2. 多次独立测试可出现七种职阶；每次先从七个有效职阶中等概率抽取，再从该表随机角色。当前各一人；少量实测不用于判断概率公平，自动测试另覆盖候选数不等的情况。反复读取同一刻存档可能复用相同随机序列，可让游戏经过不同时间再召唤。
3. 检查正面/侧面/背面、头像、装备和库存；特别检查服装遮挡与赫拉克勒斯全身渲染。七名角色均有 MoonWorld 魔力、契约、灵体切换和“测试宝具_魔力爆发”；灵体/实体来回切换与读档后外观仍正确。正式宝具继续由前置实现，不代表已接入 MoonWorld 结算。
4. 首召后查看“圣杯战争”任务及工坊，应只有一个敌方阵营，职阶不同于玩家。触发既有中文突袭测试或进入工坊，敌方应保持任务记录的那名英灵，外观/装备正确；撤离再战仍是原 Pawn。
5. 首召前、首召后、敌方休整时分别保存读取；核对资格、契约、开战时间与双方身份。旧 Saber/Archer 战争不能换人、重开或增加敌方。
6. 开发者召唤入口仍遵守同一事件资格、落点和池规则。自动失败注入覆盖空池、无异职阶对手、前置初始化失败（己方及敌方）、生成/绑定/工坊失败后的无残留与资格保留；真实 XML 加载、前置渲染与实际存读档由游戏确认。

### 独立行动与跨图魔力（本轮优先验收入口）

准备：完全退出并重启游戏，保留更新前存档副本。新增 Stat/Hediff Def 需要重启。以下规则替代历史小节中“世界旅行不结算”“玩家宝具必须主从同图”“形态切换必须同图”的说明；此前取消强制同队离图的行为保持。

1. 同图选从者，魔力栏标题与检查面板显示最低维持魔力：实体 30、灵体 10。御主留守，从者进入不同地图后为 60/20；同一远行队或同组旅行运输工具为 30/10，分属不同队伍为 60/20。分别装在同一地图的舱中使用所属地图判定；两个空地图引用不能判作同行。
2. 御主安全线设为 100%，从者食物调至转魔阈值以下，魔力调到 45、保持实体且无伤：同图不应断供，分离应出现“魔力不足”；每 250 Tick 维持费用仍约 0.025，不翻倍。已有轻伤时，自愈只使用有效维持线以上的魔力；汇合后维持线自动降低。灵体在 10 至 20 之间复测。供魔/进食转魔打开时可能把魔力补过阈值，不能据此误判修正不生效。
3. 扩展点：选中异图从者，开发者动作菜单主层 `MoonWorld -> 选中从者：切换独立维持测试能力`。临时 Hediff 使用原版 statFactors 0.5，使默认分离倍率从 2 降到 1，显示 30/10；再次点击移除后恢复 60/20。同图添加不应把维持线减半。此测试能力不自动授予任何从者，测试结束移除。
4. 御主留守基地，从者独自进攻工坊。直接选从者释放“测试宝具_魔力爆发”，应有原版高爆特效并扣 40 魔力，正常冷却。主动灵体化、健康恢复后的实体化可用；危险伤势、非站立格及无效契约仍拒绝。灵体仍不征召、攻击或施法；御主不在同图时不会闪现追往另一地图。
5. 分离时不能给从者新施加令咒过载，不扣令咒。出发前已经施加的过载仍可在外出后成功释放时消费一次。奇迹重铸没有新增效果或次数；普通召唤资格不因旅行改变。
6. 观察单从者远行队、主从同队、御主在远行队而从者在地图，以及普通运输舱装载/飞行/落地。魔力在统一周期内回复、供给、扣维持并用于自愈；两人同队御主不得回魔两次，同一从者在地图和旅行列表过渡时不得结算两次。确认原版食物消耗与进食正常，灵体不进食转魔。冷冻/暂停者不被新的主动结算唤醒；被俘御主不能供魔，外出的自由从者仍扣维持。
7. 在分离、同队旅行、飞行、落地、低魔力断供期间分别保存读取，检查 Need 库存、Hediff 年龄、契约、存在状态、资格、开战时间及 Quest；不要因本次新接入另加一套断供计时。原版健康 Tick 负责推进 Hediff 年龄。实际旅途中断供达到期限、进入战败灵体的流程需实测。
8. 敌方在异图突袭或无地图的场外休整时也采用分离阈值，固定 240/天供魔保持。确认受伤敌方能恢复、到期再袭，工坊进攻/撤离再战及任务结果保持。

自动检查覆盖生产魔力周期、同行归属、阈值和扩展倍率、独立施法与失败回滚、生命周期权限；仍不代替 Unity、原版属性实际叠加、运输与 Scribe 读档。Odyssey 重力船、任务专属传送及第三方容器未作为本轮验收范围；原版枚举可能包含这些对象，不代表其同行归属与全部行为已适配。

### 取消主从强制同队离图（本轮优先验收入口）

1. 完全退出并重启游戏，保留更新前存档副本。进入交战中的魔术工坊，分别测试御主先从地图边界走出、实体从者先走出。都应按原版建立或加入远行队，不弹出契约配对拒绝、不停止离图动作；地图内还有玩家成员时地图保持。
2. 主动灵体和战败灵体分别测试：御主先从边界撤退，灵体应走原版出口汇合附近可加入的御主远行队；不要提前把远行队移远。只选灵体点击“撤离地图”，也应能独立出场，无需御主先走。出口封闭时应提示无可用出口，不能穿墙或瞬移到世界地图。
3. 两人同图且没有旅行安排时，灵体仍跟随并在距离过远时闪现。御主进入另一个地图、装舱或处于世界远行队时，灵体不能使用其旧坐标闪现；不存在可汇合远行队时留在当前地图。两人重新同图后恢复跟随。
4. 只带御主、只带实体从者、只带灵体分别组建/重组远行队；不能因缺少契约伙伴而拒绝。灵体接到原版前往出口的旅行职责后自行走到出口，不能闪现回留守的御主身边。取消组队后恢复同图跟随。灵体仍不搬运物资，带货测试需另有能搬运的成员。
5. 使用不同运输舱编组分别装载御主和灵体，应允许单独登舱、发射。御主留在地图另一端时灵体不能闪现出舱；御主先登舱也不能让灵体卡住。原版燃料、容量、路径要求仍适用。
6. 在御主已出场而灵体还在出口途中、灵体单独撤离途中、两人位于不同地图、灵体集合或装舱中分别保存读取。确认没有非法位置、重复 Pawn、契约丢失、状态重置及红字。
7. 最后一名玩家离开工坊后，地图应卸载，敌方主从保留原伤势与魔力并进入既有休整流程；工坊保留。复测敌方撤退、到期再袭与战争 Quest 状态。返回基地后检查供魔、灵体和实体控制。

自动验证：离图与灵体旅行 25 项、敌方索敌/撤退 28 项、召唤/战争/工坊 113 项宿主替身场景；另核对 25 个 Harmony 补丁目标及 15 份 XML。没有执行 Unity 寻路、实际闪现、原版远行队完整流程或真实 Scribe 读档，以上游戏步骤待确认。

本轮移除全部主从配对否决，不新增世界地图魔力周期、跨图传送或单独出击额外消耗。灵体仍不能工作、征召和施法，形态切换及宝具原有同图条件保持。以下历史同队离图限制均以本节为准。

### 开放简易魔术工坊（本轮验收入口）

1. 完全退出并重启游戏。可使用已首召、有工坊且战争进行中的旧档；主从可以同队或分别旅行，不再要求强制配对。
2. 世界地图选中远行队，右键敌方魔术工坊，选择“进攻”。预期进入原版 Outpost 风格的简单据点，有建筑、少量原版防御；没有额外生成普通守军或重复主从。御主使用原版防守行为，从者沿用优先攻击英灵及测试宝具逻辑。
3. 检查敌方是本届原御主和原从者，契约、装备、魔力、伤势保持。若从者正在基地突袭地图上，工坊只出现御主，不能把从者复制或瞬移回来。
4. 用敌方刚战败撤退的副本进攻：其从者保留伤势、低魔力及战败灵体；完全满足现有休整出战条件才在入场时恢复实体。进攻途中休整完成属于正常情况。
5. 战斗中保存读档：双方位置、契约与伤势保持，没有额外主从。杀死敌方御主或让从者湮灭时，战争 Quest 成功；普通战败、灵体及拆掉建筑均不直接判胜。
6. 玩家未取胜时从地图边缘分别撤退；安全后也可使用原版重新组织远行队。预期地图正常卸载，存活敌方主从返回世界 Pawn，工坊位置保留。再次进入仍是同一主从、原伤势和魔力，不补满或复制。
7. 胜利后可按原版整理远行队离开，工坊在地图卸载后移除；战争历史保留，无后续突袭。返回基地后验证供魔仍正常。

范围：本版仅远行队入口，暂不开放空投/穿梭机/重力船进入或定居。布局复用原版生成；撤离后再次进入可能重建建筑，不保留建筑破坏，关闭额外战利品生成。敌方在工坊地图打开期间从外出突袭返回时不会即时传送入场；重新进入卸载后的工坊才重新安排场外主从。多个工坊、逃脱后新建 Site、精细设施和正式宝具均未实现。地图生成、原版撤退按钮与真实读档需游戏内确认。

### 七职阶与敌方主从首版（待游戏内验收）

本节是当前新增切片的验收入口。战争预设 Saber、Archer、Lancer、Assassin、Caster、Rider、Berserker 七个职阶席位，目前仅前两个有参战者。召唤成功只确定对席；敌方通过独立调试入口部署一次，不会自动袭击。其余五席留空，不生成替代角色。

5. 把过载从者魔力清零并保存、读档。预期：过载仍在、御主令咒计数正确；实体化后成功施放一次，魔力不扣、伤害为 80，过载消失且不会再次扣令咒。第二次释放恢复正常费用。取消选点或无效目标不消耗已挂起的过载。
6. 冷却中保存读档，确认 Ability 只存在一份且剩余冷却没有重置。奇迹重铸、契约、玩家成员身份、灵体跟随和 `warStartTick` 不变。测试结束后检查日志无新的 MoonWorld 异常。

离线验证：`Tests/run-noble-phantasm-tests.ps1` 编译实际 Ability 和结算服务，替身注入爆炸创建、生成、初始化和冷却记账异常，验证资源返还、过载恢复和残留爆炸清理；这不替代原版选点、Job、渲染或真实存档测试。原版爆炸初始化已经播放的瞬时音效、烟尘与热量不承诺在异常时撤销；回滚针对资源、过载、冷却及尚未执行伤害 Tick 的爆炸实体。

### 原型依赖接入检查

1. 使用召唤前的测试存档，准备有效御主；关闭开发者模式，从御主的“召唤从者”命令生成新从者。检查身份为 `GWW_Artoria` 或 `GWW_Emiya`，而非旧 `MW_*`。两种入口必须使用同一候选池。
2. 阿尔托莉雅应保留原型的固定头型、肤色、发型、锁定礼装和圣剑；卫宫应保留原型外观、锁定红衣、主手弓，以及物品栏的干将·莫邪。检查四个朝向与肖像，穿着礼装时不应露出原版身体。
3. 在一次性测试存档中用调试工具解除礼装锁定并脱下：原版身体应恢复；重新穿上礼装：原版身体应隐藏。此行为由原型补丁负责。
4. 确认新从者为玩家成员，拥有从者魔力、契约御主与灵体化命令。切换灵体、实体，检查衣服与头发透明度及身体隐藏能同时正常工作。
5. 保存并读档，检查身份、装备、身体隐藏、契约和首次 `warStartTick` 保持；本届常规召唤资格已用，召唤仍不可用。
6. 在另一份召唤前存档中抽取另一名角色复测。旧版迁移 Pawn 仅保持读档兼容，不作为新接入的外观验收对象。

原型的宝具及武器功能随内容依赖加载，但本轮未将其纳入 MoonWorld 魔力消耗或令咒规则，不作为这些系统已经完成的证据。

### 令咒与奇迹重铸（待游戏内确认）

1. 选中有效御主并确认命令栏显示“令咒：3 / 3”。已有旧存档也应自动显示初始计数。
2. 让己方契约从者进入战败灵体化，或使用健康调试工具添加 `MW_SpiritDamage`，确认御主命令栏出现“奇迹重铸：<从者名>”。
3. 点击命令。预期：从者全部原版伤势（包括伤口和疤痕）及灵基受损状态被清除，令咒变为 2 / 3，若可实体化则保持原有灵体状态规则。
4. 对同一从者再次施加灵基受损并连续成功使用，直到令咒变为 0 / 3。预期：命令不可用，御主的“令咒” Trait 被移除；保存并读档后计数仍为 0。
5. 在无灵基受损、目标已湮灭、目标不属于该御主或令咒为 0 时检查命令。预期：命令不可用，点击失败不扣除令咒、不改变其他契约状态。

### 机制回归检查

1. 选中一名殖民者，执行 `MoonWorld -> 将选中殖民者设为御主`。
   预期：该 Pawn 获得魔力回路与魔术师位阶特性，并拥有 `御主魔力` Need；不会同时出现 `从者魔力` Need。仅在本届尚未接取时，该调试入口会通过同一服务指定他接受事件；不能绕过已用资格。精确测试回满请另用“选中御主：魔力回满”。
   在召唤从者前将御主魔力减少 10，等待一个结算周期或执行一次立即结算。
   预期：御主即使尚未绑定从者也会恢复魔力；默认 250 Tick 周期恢复 1 点。
2. 保持该 Pawn 被选中，在可站立格执行 `MoonWorld -> 在鼠标处召唤测试从者`。
   预期：出现一名玩家阵营从者，可以直接征召或分配工作，并只拥有 `从者魔力` Need。
   预期：从者使用原版殖民者流程满足长期需求，不按访客停留计时主动离开地图。
3. 推进游戏时间，直至经过一次魔力结算。
   预期：御主魔力自然恢复；高于御主保留阈值的部分分配给所有未湮灭且未满魔的契约从者，不受实体或灵体形态限制；随后扣除从者维持消耗。
   可用开发者菜单 `MoonWorld/魔力测试` 中的按钮直接回满、增加、减少或清空魔力，并可立即执行一次结算。食物转魔按 10 点饥饿值换 1 点从者魔力。
   预期：从者的睡眠需求不会下降，也不会因睡眠需求生成睡眠行为。
   让受伤从者的魔力略高于实体化维持线并执行一次结算。
   预期：自愈最多消耗维持线以上的魔力，不会因治疗自身而跌破维持线。
   使用原版健康调试工具给从者添加“背痛”，并保证其维持线以上至少有 40 点魔力。
   预期：普通伤口先按每周期上限恢复，随后“背痛”被完整治愈并消耗 40 点魔力；完全缺失的器官或肢体不会再生。
4. 用普通殖民者武器攻击从者。
   预期：伤害被吸收。
5. 使用火焰等环境伤害攻击从者。
   预期：从者会受伤。
6. 通过原版正常方式杀死御主。
   预期：已契约的从者立即湮灭。
7. 重新准备一组存活的御主与从者，选中御主并点击 `灵体化：<从者名>`。
   预期：从者仍在地图画面中可见，身体、头发和衣物等全部 PawnRenderTree 人物层均为约 30% 不透明；检查面板显示 `存在状态：主动灵体化`。
   记录从者的食物 Need，让御主持续移动并推进一段时间。
   预期：从者只执行“以灵体状态跟随御主”，移动速度为其当前原版移动速度的 300%；4 格内停留，4 至 10 格使用原版 Pawn 寻路，超过 10 格后一次闪现到御主周围 2 格内的可站立格。正常无遮挡移动时应主要靠三倍移速追上御主；用关闭的门或墙阻断路线时，从者可能短暂受阻，但距离超过阈值后应闪现回御主附近，且不会破坏建筑或改动地形；不会工作、进食或发动攻击，食物值不变；从者魔力仍按灵体倍率支付维持消耗，并可使用灵体维持线以上的魔力自愈。
   尝试让普通攻击或环境伤害命中该从者。
   预期：敌对 AI 无法正常选定从者；即使其他机制送入伤害，灵体状态也会吸收伤害，已有伤口不会继续流血。
8. 在灵体状态下保存并重新载入，然后选中御主。
   预期：从者仍保持 30% 不透明的灵体状态并继续跟随御主，御主仍有 `实体化：<从者名>` 命令。
   让从者停在墙、关闭的门或深水格上并点击实体化命令。
   预期：命令被拒绝，从者保持灵体状态，提示必须位于可站立、可通行的格子。
   将御主移到开阔地，待从者跟出阻挡格后再次点击实体化命令。
   预期：灵体 Hediff 被移除，从者在原位置重新显现，并由原版驻点 Lord 恢复自主行动、进食与战斗能力。
9. 准备一名实体化从者，选中从者并执行 `MoonWorld/战败测试 -> 选中从者：施加普通致命伤`。
   预期：即使同一次伤害先触发倒地、随后才摧毁脑部，从者也不倒地、不死亡、不生成尸体，立即进入 `战败灵体化`；从者魔力清零，灵基受损增加一级，状态中不显示重新实体化倒计时。测试造成的致命脑部缺失被恢复，其他既有伤口和非致命缺失部位保持不变；地图上其他 Pawn 继续正常显示。
   立即尝试实体化。
   预期：若原版 `ShouldBeDead` 或 `ShouldBeDowned` 仍成立，命令被拒绝；不存在额外时间冷却。
   将御主魔力调到供魔安全线以上，并确保战败灵体从者魔力未满，等待至少一个魔力结算周期。
   预期：战败灵体从者正常获得御主供魔，并用维持线以上的魔力自愈。伤势恢复到不会立即倒地或死亡且处于可站立格后，御主可立即令其实体化。
10. 重新准备一名实体化从者，执行 `MoonWorld/战败测试 -> 选中从者：直接处决（应死亡）`。
    预期：从者按原版立即死亡并产生原版死亡结果，不进入战败灵体化，不增加灵基受损；尸体不保留灵体 Hediff，地图上其他 Pawn 继续正常显示。
