# 项目稳定性修正第一批交接

日期：2026-09-11
状态：源码、自动验证与测试部署完成；用户于 2026-09-11 确认当前合并版本验收通过，纳入本次合并交付。

## 本批目标

本批处理整体审阅中风险最高且边界清晰的问题：玩家席位误判造成的情报泄露、侦察只在玩家基地生效、战况页泄露未调查地点，以及战争 UI 在较小窗口中的滚动和排版问题。本批不调整战争节奏、事件概率、敌方目标权重或圣杯奖励数值。

## 已修正

- `HolyGrailWarEntry.IsPlayerParticipant` 使用实际玩家参战记录识别玩家席位；玩家从者缺失、消散或旧档异常时，不再把列表第一名敌人当成玩家并自动公开全部资料。
- 目击侦察改为检查所有已生成地图。只要地图中存在存活的玩家派系 Pawn，实际见到敌方从者或当前御主就会分别解锁对应情报；不再限定玩家基地地图。
- 战争报告、当前场外交战、契约、据点与右侧详情统一调用玩家席位和情报判定。未掌握任一参战方据点情报时，普通野外交战和工坊交战不会公开地块编号。
- 约战地点仍按公开信件信息显示，但发起者姓名遵守从者情报解锁；直接突袭和第十日决战仍作为玩家亲历事件显示公开位置。
- 战争记录板的五个页面各自保存滚动位置，切页后不再互相串用同一滚动偏移。
- 窄窗口隐藏英文副标题与决战倒计时胶囊，保留阶段、战争天数和存活席位；宽度不足时收起右侧详情栏，把空间留给主列表。
- 英灵详情页根据各段文本的真实计算高度生成滚动区域，长传记、职阶能力、宝具说明和当前状态不再被固定的 760 像素内容高度截断。
- 修复圣杯结局接入后两个旧测试宿主缺少最小服务类型导致的编译失败；圣杯结局自身仍由独立规则套件覆盖。

## 集中游戏验收

1. 读取一份玩家从者已经消散、缺失或不在图上的战争存档，打开战争记录板；确认列表第一名敌人不会因此显示真名、御主或据点。
2. 在约战、野外交战或敌方工坊地图让玩家殖民者实际遇见敌方从者，再只遇见其御主；确认两个字段分别解锁，普通殖民者也可作为目击者。
3. 未调查敌方据点时查看当前 AI 野外交战与历史报告；确认从者名称和交战地块各自遵守情报进度。约战信件给出的地点仍应显示。
4. 在总览、情报、战况等页面分别滚动后切换，确认各页保持自己的位置；缩小窗口，确认标题胶囊不重叠，主列表仍可读。
5. 打开一名说明文本较长的英灵详情并滚到底部，确认基础资料、参数、职阶能力、宝具、简介和当前状态均能完整看到。
6. 保存并读档，重复检查已解锁情报与各项绝对期限；重点观察 Debug Log 中是否出现 MoonWorld 红字。
